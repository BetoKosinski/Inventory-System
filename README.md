Basic system to pick up and display items information inside an inventory, structured with a modular and reusable code. Inspired on the game The Legend of Zelda: Breath of The Wild.

Commands:
- E: Interact/Collect Item.
- I: Open/Close Inventory.
- N: Increase Health.
- M: Decrease Health.
